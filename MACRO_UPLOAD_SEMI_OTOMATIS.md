# Macro Upload Semi-Otomatis

Macro ini memakai AutoHotkey v2 untuk mempercepat copy-paste data upload Shopee Affiliate.

## Install

1. Install AutoHotkey v2 dari `https://www.autohotkey.com/`.
2. Double click file `macro-upload-shopee.ahk`.
3. Buka tool Shopee Affiliate Upload Planner.
4. Pada item yang mau di-upload, klik **Copy paket**.
5. Tekan `Ctrl+Alt+R` agar macro membaca paket dari clipboard.

## Hotkey

- `Ctrl+Alt+S`: buka portal Shopee Affiliate.
- `Ctrl+Alt+R`: baca paket upload dari clipboard.
- `Ctrl+Alt+1`: copy judul.
- `Ctrl+Alt+2`: copy caption.
- `Ctrl+Alt+3`: copy hashtag.
- `Ctrl+Alt+4`: copy link affiliate.
- `Ctrl+Alt+5`: copy nama video.
- `Ctrl+Alt+V`: paste ke field yang sedang aktif.
- `Ctrl+Alt+H`: tampilkan bantuan.

## Catatan Aman

Macro ini tidak menyimpan password, OTP, cookie, token, atau session Shopee.

Macro ini juga tidak klik tombol submit/upload final. Kamu tetap login sendiri di Shopee dan memilih file video sendiri.
